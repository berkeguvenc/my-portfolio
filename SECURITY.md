# Security Policy

## Supported Versions

Currently, the following versions are being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the repository owner rather than creating a public issue. 

We take all security vulnerabilities seriously and will work to resolve them as quickly as possible. Once the issue is resolved, we will publish a patch release.
